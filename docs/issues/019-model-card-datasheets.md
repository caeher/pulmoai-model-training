# Model cards, dataset sheets and reporting matrix

**Historical milestone:** M6

**Status:** Guides and limitations documented; real trained-model cards await real experiments.

## Description

Begin records with data acquisition and complete them with actual run evidence.

## Tasks

- Record intended use, exclusions, population and weights provenance.
- Document data rights, cohort selection, labels, splits and duplicate audit.
- Link metrics/uncertainty and failure analyses to immutable runs.
- Record environment, seed, timing and resource cost.
- Map CLAIM/TRIPOD+AI/STARD items to evidence or not applicable.

## Acceptance criteria

Every figure must reference real evidence. Separate code licensing from dataset/weight rights.
